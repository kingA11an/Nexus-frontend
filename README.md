# Special Needs Resource Hub - Frontend
A fully responsive, production-ready landing page built to demonstrate frontend development and UI/UX implementation.
## Live Demo
View the live website here => (https://special-needs-resource-hub.netlify.app)

## Tech Stack
* **Structure:** HTML5
* **Styling:** Tailwind CSS 
* **Interactivity:** Vanilla JavaScript

##  Key Features
* Fully responsive layout adapting from mobile devices to desktop screens.
* Custom-built, right-aligned mobile dropdown menu.
* Optimized typography scaling and touch-friendly UI components.
* Clean, semantic HTML structure following modern web standards.
